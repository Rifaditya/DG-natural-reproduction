## 🚀 Overview

**Natural Reproduction** for Minecraft 26.2 is engineered natively against the MC 26.2 registry and entity attribute API changes. It utilizes modern `Identifier.fromNamespaceAndPath(namespace, path)` syntax and integrates directly with `DasikAnimalGeneticsAPI` to drive physical entity scale (`minecraft:scale`).

---

## 🛠️ Installation Procedure

1. **Install Fabric Loader**: Install Fabric Loader version `0.19.1` or higher for Minecraft 26.2.
2. **Download Required Mods**:
   - Download **Fabric API** (`0.150.1+26.2`).
   - Download **DasikLibrary** (`>= 1.8.15`).
   - Download **Natural Reproduction** (`natural-reproduction-1.3.4+26.2.jar`).
3. **Place in Mods Folder**: Move all downloaded `.jar` files into your `.minecraft/mods/` directory.
4. **Launch Game**: Launch Minecraft 26.2 using the Fabric profile.

For version lifecycle policies, see [[Version Compatibility|Version-Compatibility]].
